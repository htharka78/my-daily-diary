# My Daily Diary

A lightweight, installable Progressive Web App for structured daily journaling.

## Features
- Daily entries for events, thoughts and feelings, wins, lessons, gratitude and tomorrow's priorities
- Searchable diary history
- Weekly reflections with mood and energy summaries
- JSON backup/restore and text exports
- Offline support after the app has loaded once
- Responsive layout and light/dark theme support

## Privacy and storage
Entries are saved in the browser's local storage on the device. They are **not synced to GitHub or any cloud service**. Export regular JSON backups. Clearing browser/site data may remove entries.

## Deploy
GitHub Actions deploys this repository to GitHub Pages when changes are pushed to `main`. In repository **Settings → Pages**, set the build and deployment source to **GitHub Actions** if it is not already selected.
